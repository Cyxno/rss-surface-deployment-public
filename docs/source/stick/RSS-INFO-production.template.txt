AUTOMATED OPERATION
- PowerShell detects the supported Surface models and checks name, SystemSKU (allowlist from sources.json) and CPU vendor.
- Snapdragon/ARM names, refusal-list SKUs and CPU deviations are explicitly refused.
- The RSS data partition must be found exactly once (recognition paths: SF4 and SF8 install.esd).
- Disk selection: exactly one internal NVMe disk on Disk 0; multiple NVMe disks or USB on Disk 0 = safe stop.
- Image and driver archive hashes are checked against the manifest before the countdown.
- After 15 seconds, Disk 0 is wiped automatically and partitioned as GPT (EFI 260 MB, MSR 16 MB, Windows NTFS).

DEPLOYMENT
1. ADK DISM applies the model-specific Windows 11 Pro image index 1 with integrity checking.
2. The compressed driver archive is extracted, with integrity checking, to a temporary location on the target NVMe.
3. The full Microsoft package is checked against the exact INF count and injected offline via Add-WindowsDriver.
4. BCDBoot creates the UEFI boot files; bootmgfw.efi is verified.
5. On success the device reboots automatically; on any error WinPE stays safely on screen with a readable error and log.
